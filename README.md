## What it does

`main.ts` writes one line of wedding vows for a robot couple to `/output/entry.txt` — a single line, 1–160 characters, funny, with the laugh landing in the last few words.

## Run

```sh
node main.ts
```

Deterministic: the same vow every run. Node 22+ (stdlib only, no network).
